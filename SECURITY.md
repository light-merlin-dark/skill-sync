# Security Policy

## Supported versions

Security fixes are released on the latest npm version.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a
public issue for a report that contains credentials, private paths, or a working
exploit.

Please include the affected version, the narrowest reproduction available, and
the expected security boundary. Never include live credential values; use a
fingerprint or synthetic fixture.

For ordinary bugs with no sensitive details, use the public issue tracker.
